I'm a student and independent builder based in Brazil, working at the intersection of financial markets, quantitative analysis, and decision science.

My work focuses on building tools that structure complex problems — and on understanding how data, behavior, and markets interact to shape outcomes. I approach programming as a research instrument: code as a way to test ideas about markets and human decisions, not just to automate tasks.

Currently enrolled in a Systems Analysis and Development technical program at SESI SENAI. Building independently in parallel.
